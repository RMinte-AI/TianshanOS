# TianShanOS 0.6.2

本次发布合并三个更新：#47（自动化删除保护与规则配置包导入）、#48（发布与回归检查）、#49（失败提示统一与 SSH 指纹修复）。

## 自动化（#47）

- **动作模板不会被误删**：模板还被规则使用时（包括已停用的规则）不能删除，弹窗会列出正在使用它的规则；保存规则时也不能再新增对已不存在模板的引用。
- **规则配置包可以真正导入了**：导入前先预览，并检查签名、目标设备和依赖；确认后保存，当前运行的规则不变，重启后生效。同 ID 的规则已存在时，需要勾选“覆盖”。
- **“待重启”“待删除”看得见**：规则列表和首页快捷操作显示一致；待删除的规则不能再执行。
- 保存结果不确定时，页面会提示先核对再操作，不会重复提交。

## 失败提示（#49）

- 所有操作失败的提示统一写成“**哪里失败：原因。下一步怎么办。**”，中英文一致，覆盖登录、服务与重启、OTA、文件、网络、风扇、LED、证书与密钥、自动化、SSH 等页面。
- 设备说不清原因时，如实写“设备没有返回具体原因”，并提示到「终端」页查看系统日志。设备的英文原文和内部代号不再直接出现在提示句子里，点“详情”才能看到。
- 写操作断线或没有应答时，提示“…的结果未确认”，请先核对再决定是否重试，避免重复操作。
- 失败提示停留 8 秒；文件批量操作会逐项列出失败原因；密钥生成失败时保留失败阶段和清理结果。

## SSH（#49）

- 修复「测试连接」遇到新主机或主机指纹变化时，确认框弹不出来的问题。只有你核对并确认过的指纹才会被信任。
- 主机指纹变化时，确认框改为明确的安全警告：显示新旧指纹，默认选中“取消”。

## 其他（#49）

- 删除了不再使用的旧界面代码，页面脚本更小。
- 修复命令页“读日志／查进程”失败时被显示成“无输出”的问题。

## 发布与检查（#48）

- 新增统一的“CI 总门槛”：所选检查全部通过才允许发布；只改文档的修改只跑轻量检查。
- 发布前核对版本号、标签和中文发布说明是否一致；该版本已经发布则跳过，不会重复发布或移动标签。
- 固件构建后，会加载真实生成的 WebUI 做检查，资源缺失或脚本语法错误会被拦住。

## 升级须知

- 请同时更新 `TianShanOS.bin` 与 `www.bin`。只更新其中一个时，部分失败提示可能显示原因代号。浏览器若仍显示旧界面，请强制刷新。
- 首次启动新固件时，规则存储会自动迁移到新格式；迁移后不建议降级回旧版本。
- 导入规则配置包前，设备需要已配置可信的配置签发者，并已同步时间。
