# 0.6.0 发布验证与验收边界

本次提交包含当前工作区已完成的 WebUI 重设计、SSH 主机登记与恢复修复、风扇温度监控修复，以及 0.6.0 版本与中文发布说明。

## 本轮实际验证

- ESP-IDF 5.5.2 独立目录构建成功，主固件基础版本为 0.6.0，应用镜像 2,184,448 字节，3 MiB 应用分区剩余约 31%。
- 构建生成的 13 个 gzip 文件逐一解压，与同目录压缩前文件一致。
- `npm test --prefix tests/prompts`：40 项通过，覆盖双语翻译、参数、业务错误、操作未知状态及动态组件提示。
- `npm run test:browser --prefix tests/prompts`：40 项通过，使用实际 Chrome 和当前产品页面，包含新版确认弹窗取消不写入、危险确认默认聚焦取消、Enter 不自动继续、Esc 取消和显式确认。
- `bash tests/runtime/run_all.sh`：全部通过，包含实际生产 SSH 登记函数、HTTP 部分结果序列化、NVS/SD 故障与并发导入备份、旧响应覆盖防护及自动化生命周期回归。
- `bash tests/fan_monitor/run_host.sh`：8 组通过，覆盖手动、关闭、禁用、温度服务忙、自动、曲线及温度监控开关。
- `python3 tests/release/test_release.py`：3 项通过，覆盖当前版本/说明一致性、错误标签与缺失说明拒绝、上游 main/tag 发布而 fork/PR 不发布。
- `python3 tests/release/test_web_minify.py`：2 项通过，覆盖 CSS calc 加减号空白、`:not()` 与媒体查询 `not` 的不同语法。
- 当前源码及实际压缩构建产物：各 8 个路由 × 2 种语言的本机替身加载通过，脚本/资源错误及未知端点均为 0。

## 自动发布路径

PR 运行 WebUI、运行时/风扇和固件构建检查。上游 `RMinte-AI/TianshanOS` 的 main 在 PR 合并后触发工作流，三个检查任务全部通过后读取 `version.txt`，生成 `v0.6.0`，从 `docs/releases/v0.6.0.md` 读取中文说明并上传 CI 构建的 bin 与刷写映射。Release 指向工作流检出的提交；PR 和 fork 上的构建不发布上游 Release。

## 证据边界

以上结果是本轮本地构建、主机回归与浏览器替身证据，不代替 GitHub Actions 的实际结果。本轮没有刷入 0.6.0，也没有重新执行真实 SSH 部署、证书签名、OTA 升级或硬件长时间负载验收。此前 0.5.2 分支实机刷写与启动记录仅作为历史证据。

`docs/macos27/` 中旧候选的检查结论保留其原日期与范围，不能作为当前版本全面通过的证明；部分历史实验脚本需要本机浏览器工具路径及 `output/` 中的原始数据，未全部接入 CI。Safari、真实手机输入、全状态对比度和绘制性能仍有独立验收边界。
