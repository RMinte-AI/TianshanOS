# 0.6.1 发布验证

## 本地验证

- 从完整工作区源码快照在全新目录使用 ESP-IDF 5.5.2 构建；基础版本 0.6.1，主固件 2,202,336 字节，3 MiB 分区剩余约 30%。
- WebUI 静态回归 122 项、真实浏览器模拟回归 232 项通过，覆盖中英文、页面生命周期、输入、服务操作、删除保护、密钥、缓存、LED 滤镜和 LPMU 日志。
- `tests/runtime/run_all.sh` 全部通过，覆盖实际生产函数、模拟 SSH/NVS/SD 故障及 ASan/UBSan。
- 证书主机回归通过，包括真实 MbedTLS 生成和解析 CSR；风扇输出、保护连续性、回落轨迹及页面回归通过。
- WebSocket 操作适配器回归及 Release 标签、中文说明、压缩资源检查通过。
- 默认 `build/` 下五个镜像和刷写映射来自同一次干净构建，版本和 SHA-256 见 `build/firmware-manifest.json`。历史构建目录保留作追溯，不是默认刷写入口。

## 发布流程

PR 运行 Ubuntu 上的 WebUI、运行时与固件构建检查，新增风扇回落／输出、WebSocket 适配器和真实 CSR 签名解析检查。上游 main 合并后，全部检查成功才自动创建 `v0.6.1` Release，读取 `docs/releases/v0.6.1.md` 的中文说明并上传 CI 构建的镜像。fork 和未合并 PR 不发布上游 Release。

## 验收边界

本地测试不替代 GitHub Actions 的实际结果。本轮“重置固件”按干净重建处理，没有擦除设备、NVS 或 SD，也没有将最终发布构建刷入设备。

此前在该设备上确认了 LPMU 错误密码、无互联网时正确失败、具体原因提示和日志展开；尚未完成成功接入互联网、SD 不可用、多次执行内存趋势，以及风扇真实热负载的长期验收。浏览器用例使用明确标记的本地模拟接口；模型轨迹不是实际散热性能证明。
