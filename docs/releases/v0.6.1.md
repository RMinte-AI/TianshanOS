# TianShanOS 0.6.1

本次集中修复设备控制、配置保存和操作结果反馈，保持现有界面风格。

- **风扇**：缩短负载结束后的多余风量回落；温度观测中断或更换来源时重新计时，避免过早解除高温保护。读数只显示成功下发的 PWM，设置失败和未知输出不再冒充成功，手动目标在保存、恢复后保持一致。
- **自动化**：修复动作执行中的大对象栈占用；服务启动、核实和停止通过任务队列执行，避免阻塞接口和重复启动。运行中或状态未确认的服务配置不能直接删除。
- **配置保存**：编辑动作模板直接更新，写入失败保留原配置；修复 LED 滤镜参数、异步选项和导入导出字段丢失。零值、负数、表达式和条件值类型在再次编辑时保持一致，非法输入保留草稿并明确提示。
- **SSH**：修复公钥注释含引号等特殊字符时的部署命令，以及长命令截断。恢复首次部署新主机的登记流程，已知主机指纹变化仍拒绝连接；页面切换和迟到消息不会覆盖新的执行窗口。
- **密钥**：修复元数据、索引写入失败却提示生成成功，以及 ID 子串误判。新建不会覆盖已有密钥；失败清理、重复提交、列表乱序和保存后刷新失败均有明确反馈。
- **证书与输入**：修复 CSR 特殊字符处理和长度边界；文件名、路径、数据组件数值等输入不再被静默修改或错误回填。
- **LPMU 接入**：每次执行输入 sudo 密码；只有脚本完整报告互联网正常和配置完成才显示成功。失败窗口优先显示脚本的具体原因，底部可展开完整执行日志；日志存于 SD 卡，分页读取不再卡住或混入下一次执行。
- **界面**：统一接入结果弹窗的白色分组、黑色展开标签和字号层级；修复数据组件窄屏布局、旧资源缓存及页面离开后的残留弹窗，并同步中英文提示、品牌图标和仓库链接。
- **构建与发布**：修复 Linux 测试目录、数学库链接和 ESP-IDF 缓存的 Python 环境匹配，补充风扇、WebSocket 和真实 CSR 回归；合并后自动生成带中文说明的 Release。

升级请同时更新 `TianShanOS.bin` 与 `www.bin`。浏览器若仍显示旧界面，请强制刷新。
