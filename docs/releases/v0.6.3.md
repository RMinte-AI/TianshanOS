# TianShanOS v0.6.3

## 自动化与可靠性修订构建

正式版本保持 **0.6.3**，使用新的提交哈希和构建时间后缀区分修订，例如 `0.6.3+提交号.构建时间`。本页末尾的“本次构建”由通过 CI 的发布流程填写。

### 新增与完善

- **普通 WebSocket 数据源正式可用**：接通连接、接收、字段映射和启停／编辑／删除生命周期；补齐分片消息的空结束帧处理，网页测试与实际采集保持一致。
- **REST 与 Socket.IO 配置生效**：外部 REST 采集采用保存的 GET／POST 方法；Socket.IO 的 HTTPS 地址对应 WSS，并使用现有证书信任策略。
- **规则执行 SSH 高级设置**：普通 SSH 引用命令支持保存的成功／失败模式、提取规则和匹配后停止设置。匹配后达到执行期限时保留匹配结果，没有匹配才报告超时，退出码独立保留。
- **运行记录独立管理**：删除或修改配置后，旧运行仍可按原主机信息核验、查看日志和停止；保留未知状态，不把历史记录误当成当前运行。
- **配置维护闭环**：增加用户变量删除、SSH 主机和数据源编辑、无主机命令的重新关联入口；同编号新建不覆盖已有命令或数据源，删除／替换明确处理依赖及受影响对象。

### 问题修复

- 修复未授权读取数据源认证信息的问题；保留 root 的敏感配置管理权限，并恢复 admin 首页的运行记录、状态、日志与停止入口。
- 修复旧 SSH 请求晚返回时写入新命令／新变量、重启后旧运行误关联同编号新命令，以及旧日志检测覆盖较新核验结果的问题。
- 修复失败轮次在相关配置修改后仍受旧冷却限制的问题，同时保留成功轮次和手动执行的正常冷却。自动暂时失败仍按原约定每 30 秒重试、最多 360 秒；手动失败不自动重试，已完成的前置步骤不重复执行。
- 修复数据组件读取失败被当作空配置、连续保存被丢弃、保存失败仍提示成功，以及旧请求关闭新编辑弹窗的问题。
- 修复旧数据源测试结果覆盖新弹窗、含引号／Unicode 的规则编号编辑失效，以及 SCP 提前结束仍报告下载成功的问题。
- 修复 SSH 主机指纹回显丢失最后一位的问题，完整保留 64 位 SHA-256 指纹；没有关闭或放宽主机身份校验。
- 完善密钥删除影响说明和失败反馈，修正删除提示与实际删除／停用结果不一致的问题。
- 统一自动化表格的列宽、对齐和长名称显示，保留既定状态灯、日志入口、命令展开、按钮排列和弹窗布局。

### 文档与交付

- 收录本地整理的中英文用户指南、相关说明及生成／检查脚本；历史指南按版本目录保留。
- `tianshanos-local-work-archive-20261030.zip` 保存历史 PDF／渲染输出及原本地构建快照，**属于历史归档，不是本次刷机包**。
- 本次修订不再改变 0.6.3 分区方案、64 条规则容量及应急副本范围。有 SD 卡时，应急副本仍只在用户主动保存时更新；删除配置不会自动停止远端进程。

## 界面修订

- 指令列表使用完整灰条，操作按钮三列两行、等高并垂直居中；命令默认收起，展开后铺满灰框内部，保留完整多行内容。
- 配置与备份重新分组，状态、保存／恢复说明、按钮和副本范围清楚分开；应急模式和重新插卡的选择保持原逻辑。
- 删除弹窗分开显示删除方式、关联检查、服务说明及确认按钮；支持长名称换行，修正 Safari 切换方式后的键盘焦点。
- 同步完善中英文、手机和横屏布局；存储分区及业务执行逻辑保持不变。

## 0.6.3 主要变更

**升级必读：本次固件修改了分区表，从旧版升级必须使用 USB／串口升级包刷机，不能只通过 OTA 更新。**

本次更新集中解决自动化配置保存、引用删除和网页操作问题，并重新整理配置存储。

- **配置存储重整**：原密钥区专存密钥，新增 128 KiB 系统配置区和 2 MiB 自动化应急配置区；网络、风扇等系统设置与密钥分开保存。
- **SD 卡与应急模式**：规则、动作模板、SSH 命令和主机等关联配置统一保存。日常编辑写入 SD 卡，手动保存内部应急副本；无卡时自动使用内部配置，允许编辑并直接保存。重新插卡后，可选择使用卡内配置或把当前配置写回卡内。副本只包含配置，缺少图片、字体时明确提示。规则上限为 64 条。
- **删除与运行状态**：统一引用检查、替换和解除引用操作，支持强制删除并停用受影响规则；远端服务状态不再阻止删除配置，删除不会停止远端服务。修正配置变化后无法重新确认删除、数据源连接状态显示错误等问题；修复 SSH 私钥不可用时的命令缓冲区泄漏、短时后台命令无法再次启动，以及模板规则未在执行前检查后台服务的问题。
- **网页体验修正**：统一配置管理与来源提示，改进表单、弹窗、响应式布局、字体和图标；完善中英文提示。修复含引号 ID 的按钮失效、命令图标渲染和读取失败一直显示加载中的问题。
- **代码清理与验证**：移除旧分散存储、重复删除接口和过时提示，更新运行、存储、网页与打包检查。

## 升级说明

首次从旧分区布局升级，必须使用本 Release 的 **USB／串口升级 ZIP 包**，按包内 README 操作，不能仅通过 OTA 更新应用固件。升级包包含新分区表、固件和网页，会更新两个应用槽，并保留原密钥和 SD 卡。客户交付按既定的“清空旧配置、重新配置”流程实施；升级工具保留密钥和 SD 卡，不等于自动清空卡内配置。已采用新布局的设备可使用后续兼容更新。

配置包仍执行证书用途和签名验证；只有具备配置签名用途的证书才能签署可导入的配置包。
