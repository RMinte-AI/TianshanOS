# TianShanOS v0.6.3

**升级必读：本次固件修改了分区表，从旧版升级必须使用 USB／串口升级包刷机，不能只通过 OTA 更新。**

本次更新集中解决自动化配置保存、引用删除和网页操作问题，并重新整理配置存储。

- **配置存储重整**：原密钥区专存密钥，新增 128 KiB 系统配置区和 2 MiB 自动化应急配置区；网络、风扇等系统设置与密钥分开保存。
- **SD 卡与应急模式**：规则、动作模板、SSH 命令和主机等关联配置统一保存。日常编辑写入 SD 卡，手动保存内部应急副本；无卡时自动使用内部配置，允许编辑并直接保存。重新插卡后，可选择使用卡内配置或把当前配置写回卡内。副本只包含配置，缺少图片、字体时明确提示。规则上限为 64 条。
- **删除与运行状态**：统一引用检查、替换和解除引用操作，支持强制删除并停用受影响规则；远端服务状态不再阻止删除配置，删除不会停止远端服务。修正配置变化后无法重新确认删除、数据源连接状态显示错误等问题。
- **网页体验修正**：统一配置管理与来源提示，改进表单、弹窗、响应式布局、字体和图标；完善中英文提示。修复含引号 ID 的按钮失效、命令图标渲染和读取失败一直显示加载中的问题。
- **代码清理与验证**：移除旧分散存储、重复删除接口和过时提示，更新运行、存储、网页与打包检查。

## 升级说明

首次从旧分区布局升级，必须使用本 Release 的 **USB／串口升级 ZIP 包**，按包内 README 操作，不能仅通过 OTA 更新应用固件。升级包包含新分区表、固件和网页，会更新两个应用槽，并保留原密钥和 SD 卡；请保留原 SD 卡并保持供电，等待首次启动迁移完成。已采用新布局的设备可使用后续兼容更新。

配置包仍执行证书用途和签名验证；只有具备配置签名用途的证书才能签署可导入的配置包。
