# 0.6.2 发布验证

## 本地验证

- 在已合并最新 main（含 #47、#48）的源码快照上，用 ESP-IDF 5.5.2 在全新目录构建：版本 0.6.2，主固件 2,225,984 字节，3 MiB 分区剩余约 29%，无编译警告。
- WebUI 静态与目录检查 133 项、真实浏览器回归 720 项通过，覆盖中英文失败提示 189 个场景、删除保护弹窗、规则配置包导入、SSH 指纹确认、密钥生成、LPMU 接入等；离线终端回归 4 项通过。
- `tests/runtime/run_all.sh` 44 项、规则包 8 项通过；WebSocket 四个入口、风扇输出与回落、发布与 CI 策略检查通过。
- 构建产物检查：`www.bin` 与刷写映射一致，13 个成品资源的语法和 gzip 通过；加载真实成品 WebUI 的冒烟测试与缺资源负例通过。

## 发布流程

合并到上游 main 后，GitHub Actions 运行全部检查；全部通过才自动创建标签 `v0.6.2` 并发布 Release，正文取自 `docs/releases/v0.6.2.md`。发布前会核对标签、`version.txt` 与编译版本一致，且该版本尚未发布。

## 验收边界

本地验证不替代 GitHub Actions（Ubuntu、Node 22）的实际结果。证书回归需要在本地另行编译 MbedTLS，本次没有重跑（相关代码来自 #47，合并时没有改动）。没有在真机上验收：SSH 失败阶段的判断、新的指纹警告弹窗和各提示的实际手感。仓库 `build/` 下的默认刷写镜像仍是 0.6.1，0.6.2 的镜像以 Release 附件为准。
