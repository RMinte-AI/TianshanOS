# TianShanOS 0.6.0：熟悉的控制台，焕然一新的体验

这次更新最值得打开看一看的，是整个 WebUI。TianShanOS 0.6.0 对控制台进行了大幅重设计：从登录后的第一屏，到日常查看状态、调整设备、管理文件和执行指令，再到每一次展开设置和确认操作，界面的视觉语言与交互形式都发生了明显变化。

新版以 macOS 风格的清爽桌面界面为方向，用更克制的色彩、清晰的文字层级、轻盈的半透明表面和统一的图标，重新组织设备管理中的密集信息。原本容易挤在一起的状态、读数和操作，现在通过卡片、分组与留白建立更明确的关系。打开控制台时，先看到设备正在发生什么，再找到接下来可以做什么，整个页面更有秩序，也更有新鲜感。

这种变化贯穿系统概览、网络、LED、文件、SSH 指令、自动化、安全和固件升级页面。不同页面不再各自使用一套表现方式，按钮、表单、列表、状态标签和设置弹窗以统一的节奏呈现。常用设置通过更集中的面板展开，确认框也融入控制台本身；危险操作有明确的视觉提示，取消与继续的选择更清楚。终端保留熟悉的命令工作方式，同时采用与新版界面协调的字体、间距与配色。

我们希望这次升级带来的感受，不只是“换了一套颜色”，而是让这台设备的日常管理更像一个完整、现代的桌面工具。无论是在宽屏上查看多项状态，还是在较窄的窗口里操作，界面都围绕同一套布局与信息层级展开。中文与英文提示也随新界面一起调整，让操作结果和下一步选择更容易理解。

视觉更新之外，0.6.0 同时修正了 SSH 公钥部署与主机登记的结果表达、主机配置恢复和列表刷新，以及手动或关闭模式下风扇温度读数的更新。控制台既要看起来焕然一新，也要准确反映设备实际完成了什么。

升级时请同时更新主固件 `TianShanOS.bin` 与 WebUI 资源 `www.bin`，以使用完整的 0.6.0 界面。首次打开后若浏览器仍显示旧样式，请强制刷新页面。
