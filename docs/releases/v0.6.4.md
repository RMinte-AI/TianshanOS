# TianShanOS v0.6.4

本次更新汇总 **0.6.3 首次正式发布之后的全部改进**，包括自动化、终端与文件传输、灯光、风扇、网络、电源显示及网页操作。

0.6.3 发布后曾在相同版本号下更新过固件和网页，因此部分变化可能已出现在您正在使用的 0.6.3 修订版中。这里以首次发布的 PR #52 为起点，完整列出后续 #53–#61，以及本次 #62 的内容，便于一次了解累计变化。

## 自动化与配置管理

- **数据源按配置工作**：普通 WebSocket 数据源接通连接、收数、字段映射与启停流程，正确处理分片消息及空结束帧；REST 使用保存的 GET／POST 方法，保留 URL 查询参数，读取失败后仍遵守采样间隔；HTTPS Socket.IO 使用相应的安全连接，并修复首次连接无法完成订阅的问题。
- **重连后继续更新**：网页 WebSocket 重新连接时恢复主题订阅，避免页面显示“已连接”却不再更新监控数据。算力监控停止时等待旧连接任务退出，减少旧任务干扰新连接的问题；命令行只改监控端口时保留地址及其他设置。
- **SSH 动作设置真正生效**：普通规则 SSH 命令使用保存的成功／失败匹配、结果提取和匹配后停止选项。长输出显示被截断时，已确认的匹配结果仍保留；期限届满、命令退出码与匹配结果分别处理。
- **配置与运行记录分开管理**：修改或删除配置后，已有运行记录仍使用原主机和运行身份核验、查看日志及停止。同名重建、设备重启、旧请求晚返回和日志交叉核验，不再把旧结果写给新配置或新运行。
- **保存与恢复更准确**：数据组件读取失败不当作空配置，连续保存不再丢失，保存失败明确提示。动作、数据源等导出保留恢复所需字段；取消、重选、关窗或换页后，旧读取结果不会恢复已经取消的导出选择。
- **编辑器保留当前草稿**：关闭尚在加载的规则编辑器后，旧规则的后续动作不会进入新编辑器；风扇和关机设置的迟到响应不会覆盖已修改的输入；旧请求也不会关闭后来打开的弹窗。
- **配置维护入口完善**：支持用户变量删除、SSH 主机和数据源编辑、无主机命令重新关联；同编号新增不覆盖既有对象。删除和替换说明引用影响，保留强制删除、停用受影响规则和独立运行记录的既有规则。
- **重试与冷却保持操作意图**：失败轮次不再被已修改配置的旧冷却限制；成功轮次及手动执行维持原冷却。既有自动暂时失败重试仍按原周期和期限执行，手动失败不自动重试，完成的前置动作不重复执行。

## 登录、权限与安全显示

- 修复重启后登录锁定时间可能异常延长的问题；旧会话检查迟到时，不再退出后来建立的新登录，当前会话真正失效时仍正常退出。
- 补齐部分 HTTP／WebSocket 入口的登录与权限检查，修复会话标识泄露带来的冒用风险及安全接口分类越界问题；保留公开订阅和原有角色权限。
- 数据源认证信息等敏感配置继续由 root 管理，同时恢复 admin 首页允许使用的运行状态、日志和停止入口。
- 首页组件表达式不再作为任意网页脚本执行；变量、数据源和命令中的外部字符串按文本显示，避免被当作 HTML 执行。
- SSH 主机指纹完整显示 64 位 SHA-256 值，不再遗漏最后一位，主机身份校验没有关闭或放宽。完善密钥删除影响说明及失败反馈。

## 终端、SSH 与文件操作

- **输出与执行结果分开**：终端后台执行、转发停止与任务退出完成交接；连接容量不足时明确拒绝，减少连接被占满后网页或终端卡住的情况。断线后可以补查执行结果，输出是否完整与命令是否完成分别报告；没有输出不再直接等同于失败。
- **长输出与长命令更安全**：统一控制台输出路径，长内容按完整 UTF-8 字符截断并显示提示，格式化正文上限为 16 KiB；修复命令输入正好达到最大长度时的结束标记越界问题。
- **SSH 命令行管理修复**：通过安全存储中的密钥执行命令或连接检查时，正确传递所选密钥；清空已保存指纹、确认清空已部署主机记录，以及远端仅剩待撤销公钥时的撤销操作均得到修正。转发持续阻塞时停止，不再提前释放后台仍使用的资源；相关临时任务退出时正确释放资源。
- **SFTP 请求互不干扰**：每笔请求单独保管认证密钥，避免并发操作互相覆盖或释放。目录正常结束与读取失败分别处理，中途出错不把半张文件清单显示成完整成功结果。
- **下载失败如实报告**：HTTP 分块读取失败、SCP 文件提前结束时返回失败，不把不完整下载标成完成；失败后仍可再次操作。
- **文件选择和名称更可靠**：长英文名、中文名及子目录可按完整名称递归删除；带 `+` 或 `%` 序列的路径不再因重复解码指向另一文件。批量删除只处理确认时选中的对象，确认后新勾选的文件不会被顺带删除，原有路径保护保留。
- **命令参数与重启等待修复**：消除 `temp --value`、`net --ip` 的重复参数注册，帮助中区分查询与修改。`system --reboot --delay` 按秒正确换算等待时间，正数仍受原有 10 秒上限约束，提示与实际等待一致。

## 灯光、图片与二维码

- **取色更直观**：设备设置与自动化填充动作改用亮度、色相、饱和度滑条；拖动时预览，松手才发送一次设置。接近白色时可吸附到白色，未改动滑条不会改写旧动作的颜色。
- **单灯和连续范围设色可用**：设置连接到实际图层。设置前校验范围，停止所选底层图层的动画，保留叠字、滤镜和其他灯组；局部设色不新增重启后恢复的持久化行为。
- **模式切换与关灯一致**：图片切换纯色、关灯及全部关闭会更新相应状态，避免重启恢复旧内容；全部关闭同时清除文字及相关滤镜。命令行开灯不再被下一帧的图层内容覆盖。
- **各设备的灯效独立**：修复带颜色动画共用颜色地址，以及关闭其他灯组影响矩阵 GIF 的问题；淡入淡出使用正确的相对时间，按设定时长执行。
- **文字与二维码设置完整生效**：切换字体时协调文字任务，加载失败不使用已释放的字体；自动化文字的手动位置和对齐设置接入执行。生成二维码会停止原动画，前景色、背景图选项正确传递并保存恢复；显式黑色与旧配置默认白色分别处理。
- **损坏图片不会越界访问**：补齐 BMP／GIF 声明尺寸和数据范围检查。色彩校正已应用但向 SD 导出失败时，分别报告应用结果与保存结果，避免误报整次应用失败。

## 风扇、电源与系统状态

- **手动控制不会被旧自动调速覆盖**：同一风扇的模式、目标值到实际 PWM 提交按顺序完成，覆盖手动、关闭、紧急全速和停用操作；温度读取移出控制锁，温度服务忙时不会因此占住风扇控制锁。保留原有调速、温度失效和保护规则。
- **风扇设置保存结果可信**：曲线、模式保存失败不再显示“已保存”；网页区分目标值与最后确认的实际输出，未知输出不显示成已成功设置。修改曲线节点温度后，再改调速值仍对应同一节点。
- **电源读数正确判定有效性**：修正电源芯片数据校验，使正常协商数据可显示电压、电流、功率；坏包不作为正常读数展示，缺值与有效零值区分。
- **保护配置与查询一致**：低压保护初始化和实际启用状态分开，停用后可通过开关重新启用；修改阈值不使用未初始化的另一阈值，关机设置校验失败不提前改变电压阈值。查询读取当前配置，当前值与默认值分别显示，读取失败明确报错。
- **服务重启与资源回收修复**：LED、电源、串口控制台及网络服务按各自生命周期停止和恢复；重复停止、接口未启动和真实停止失败分别处理，避免服务显示重启却没有重新启动。电源任务停止不再直接删除持锁任务，相关任务栈预算与退出释放得到修正。
- **状态组件与诊断更准确**：双数值组件从同一次变量响应更新主、副值，分别处理缺失、恢复及零值，取消副表达式时清除旧值。内存详情避免任务数变化引起越界排序，估算值明确标注，保留实际最低剩余栈和警示阈值；配置模块列表与 GPIO 引脚映射也补齐边界检查。
- **温度绑定可在重启后恢复**：即使从未保存过首选温度源，也独立恢复已保存的变量绑定，保留自动选择、多变量权重和旧格式兼容。

## 网络与 DHCP

- **保存的网段和固定绑定按正确顺序恢复**：以太网创建时使用已校验的主机地址，随后应用匹配的地址池和绑定；AP 自定义网段也在首次发址前就绪。DHCP 地址池不会擅自改变设备主机地址。
- **固定地址归属与正常租约并存**：保留续租、释放、过期和解绑行为，动态客户端不会抢占保留地址。运行中编辑绑定不靠停止 DHCP 或清空活动租约完成。
- **重连保留用户启停意图**：显式停止 ETH DHCP 后，断链重连不会自行开启；延迟启动任务执行前重新检查状态。配置校验失败保留原服务，运行状态按实际结果报告，不把失败包装成停止或启动成功。
- **异常保存记录不会变成空配置**：绑定数量、数据长度或类型不一致时拒绝恢复并保留数据；保存时保护尚未恢复的接口，避免覆盖为零条绑定。明确清空指定接口只改变当前表，需要另行保存才写入存储。
- **DNS 初始化与客户端分发说明清楚**：修复主机地址未变化的冷启动路径遗漏 DNS 设置的问题。池中指定 DNS 时向客户端使用池值；池 DNS 留空时，当前构建向客户端下发设备在该接口上的地址。网络状态中读回的 DNS 不保证等于客户端收到的 DNS。
- AP 默认保持 `192.168.4.1/24`，默认地址池为 `.2–.101`、租约 120 分钟；仅对完整匹配且无固定绑定的旧默认记录做兼容，不在启动时改写保存记录。

## 网页体验、设备名称与升级工具

- 页面统一使用“推理计算机／应用计算机”，中英文、USB 目标、断开提示、终端帮助和当前用户说明同步；原命令参数、配置键和真实硬件型号保持兼容。
- 网络接入显示更明确的失败原因、阶段与运行状态，保留原始日志，避免把上传阶段误判成加载失败或把旧错误当成当前原因。已完成任务可从状态卡重新查看结果，刷新、关窗或离开页面期间完成后仍可访问；未知状态不伪报完成。
- 指令列表使用完整卡片和可展开正文，按钮在桌面、手机、横屏和长名称下保持可用；自动化顶部操作、配置来源和运行状态提示更清楚。公共长结果弹窗限制在视口内，摘要、详情分别滚动，收起和关闭按钮可见。
- 配置与备份、删除配置、内存、变量、组件及风扇帮助弹窗统一分组、间距和主要按钮，减少重复关闭入口、边框及叠加毛玻璃；优化 Safari 焦点、窄屏、英文长说明、图标、滑条和最小字号等细节。
- 文件上传在尚未选择文件时禁用；编辑组件图标保持原存储格式。LED 图片与二维码设置合并展示，改善选图、白色取色点及内存任务表显示。
- **OTA 按选择的来源下载**：手动 URL 升级不再优先使用另一台已保存服务器；SD 升级中止会通知实际后台流程，避免中止后继续写入或自动重启。本地 OTA 工具同时支持 `/www.bin` 和原 `/www` 路径，匹配设备的配套网页下载。
- **配置包使用当前证书身份**：证书更新后，普通包入口和导出使用当前证书；导出指纹对应包内同一份证书。保留证书用途、签名、收件人和解密校验。
- 更新中文／英文操作指南、命令和 API 说明、界面设计记录，并扩展运行时、网页、故障注入与打包回归。发布继续由完整检查把关，自动提供匹配的固件、网页及 USB／串口升级包；测试并发隔离与构建依赖检查同步完善。

## 升级前请注意

1. **先备份配置，并使用同一 Release 的配套固件和网页。** 已采用 0.6.3 新分区布局的设备，本次没有新增分区变更；可以按现有兼容升级流程更新应用和配套网页。
2. **从 0.6.2 及更早的旧分区布局升级，必须使用本 Release 的 USB／串口升级 ZIP**，按包内 README 操作，不能只刷 OTA 应用。原密钥和 SD 卡保留规则以升级工具说明为准；保留卡内数据不等于自动清空或重新配置，升级前应做好备份。
3. 网络改址、地址池及固定绑定须位于匹配网段；若保存的主机配置非法，以太网不会静默改回默认地址。可通过可用 AP 或串口修正并保存，重启后重新恢复保留的数据。
4. 将主机 DNS 留空不表示清除已经应用的 DNS；单灯／范围设色也不会另存为重启后的灯光预设。修改、应用和保存请按对应功能的说明操作。
5. 本版本的自动化、网络及风扇等已有宿主回归和构建验证；**本 PR 新增 DHCP 首次发址、DNS／租约报文和重连等真机验收仍待完成**。历史修订中的部分真机记录不代表整个 0.6.4 已逐项实机验收，也不把尚未定位的 OTA 后失联现象列为已修复。
