## 四、可验收的视觉规范

### 4.1 背景与内容层

以批准第三版为锚点：页面背景保留静态暖金与浅蓝渐变。参考基础色 `#cddbe7`，暖色 `#f8d9a4`，浅蓝 `#c4dfef`，渐变过渡 `#b9cddc / #e1d5bd / #bbd7ef / #91b7dd`。按生产尺寸适配，不能只在页面外露出一条细边让整体仍像旧版，也不能新增大面积壁纸图片、动画背景或常驻脚本。

主内容清晰稳定，接近白色；分组使用中性极浅灰（参考 `#f5f5f7`），弱分隔线（参考 `#e4e4e7`），避免旧雾银的绿色/卡其色文字、整片蓝灰底、厚重描边和层层阴影。一级分组靠底色、留白和标题建立层级，嵌套内容不要重复套厚卡片。保留各原模块身份及边界，不通过移走功能制造简约。

### 4.2 控制层与浮层玻璃

玻璃是本次批准方向的必要特征，应用于原有导航/控制表面、菜单/Popover 和适合的模态外壳。表格、日志、终端、大量正文与图表绘图区保持可读、稳定的内容表面，禁止全页玻璃化。

参考参数：顶部半透明白色约 19%–44%，blur 22px、saturate 1.35；弹窗白色约 22%–44%，blur 18px、saturate 1.45，1px 细亮边、轻内侧高光及柔和外投影。它们是起始参数，不是跨浏览器性能保证。实际以批准渲染和文字清晰度为准。

必须解决旧实现的根因：外壳近乎不透明，加上内部大白板会遮死背景。不得只增加 blur 而仍保留厚白双层。弹窗内采用透明/低不透明度分组、细分隔线；局部表格/编辑区可用更实的承载面。后方确有内容或色彩时，应能看见模糊的轮廓/颜色；同时不可让背景文字干扰阅读。禁止在弹窗里画一张假渐变冒充背景透射。

不得删除或弱化原有遮罩、焦点管理、键盘关闭、危险操作确认、滚动锁定与权限规则。逐项检查层叠上下文，确保菜单、色轮、文件选择器、嵌套弹窗不被裁切或覆盖。

不支持 backdrop-filter、减少透明度、高对比模式必须有可读实体回退；减少动态效果时去掉非必要动画。普通支持环境要交付批准的玻璃效果。若性能或可读性失败，先在局部缩小滤镜范围、消除重复模糊、调整合成层；不能悄悄将全部玻璃关闭后声称视觉验收通过。确有无法同时满足的冲突时，交付证据并将该项标为 FAIL/BLOCKED，待用户决策；其他独立工作继续。

### 4.3 字体、控件与状态

使用系统字体栈，参考 `-apple-system, BlinkMacSystemFont, 'PingFang SC', sans-serif`，不下载 SF 字体。正文/表单建议 14px，次要与技术文字至少 12px，标题按层级约 15/20–25px，数字轻字重且等宽数字对齐。不能机械复制原型中的 10/11px 小字到所有生产界面。保留数字精度、单位及完整文案。

参考圆角：主要内容面 18–23px、子分组 12–16px、普通控件 8–12px、浮层约 24–28px，紧凑按钮/导航可用胶囊；按嵌套间距保持协调，不把所有东西强制同一圆角。避免给每个小值单独加卡片。

主动作与选中状态参考系统蓝 `#087cf0`，主文字近 `#202124`，辅助文字约 `#5d6570`，以实际对比度校核。正文至少 4.5:1、大字和有意义控件边界至少 3:1；玻璃需在真实合成背景、滚动位置、hover/focus/disabled 状态检查，不能只计算令牌颜色。

普通表单可采用标签和值对齐、组内细线分隔的设置行；保持既有字段顺序、校验、帮助和错误信息，不为了造型重组功能。分段控件保留明确选中/禁用/键盘反馈，不能把所有状态都染蓝。成功、告警、危险继续保留文字和图标，不能仅靠颜色。危险按钮不可伪装成普通蓝色确认。

禁止仿系统窗口红黄绿圆点、假标题栏、Dock、无功能按钮、Apple 标志；页面是真实设备 Web 控制台。
