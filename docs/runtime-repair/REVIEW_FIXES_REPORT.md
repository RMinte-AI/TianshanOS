## 协议与产品边界

- 登记代次与操作凭证由本次开机内不复用的序号分配，耗尽时拒绝新准入。完成只释放对应占用；运行代次过期只影响结果发布，不影响自身清理。停止/取消使旧就绪证据失效。
- 删除、命令身份修改、主机身份修改与查询准入共用 binding gate。网络 I/O 不持有该协调锁；配置删除期间登记保持 deleting 门禁，删除失败不回收。快照 pin 带登记身份，旧 unpin 不减新登记的引用。
- 自动化停止关闭动作准入，最多短等 200ms；调用方和队列/执行者分别持有完成信用，全部归还且评估任务退出才报告停止。长操作仍在结束时返回“正在停止，请稍后重试”，期间 start/resume 不重新放行动作。现有网络超时继续负责结束 I/O，无外部强删。
- 停止自动化不会停止真实模型，也不会清掉运行中或未知服务的登记。延迟和重复动作会协作结束；已经开始的动作正常释放自己的快照和临时占用。
- 启动回执包含 Linux boot ID、PID、/proc start ticks。完成阶段必须与回执匹配；日志读取前后都复核同一实例。日志由本次启动重定向清空，不能用旧 ready 文本给新进程背书。
- 断网恢复复用现有 watcher 容量，最多 3 次远端恢复尝试/启动代次、5 秒间隔、20 秒调度窗口；一次已开始的 I/O 仍受自身超时约束。预算仅在新启动代次建立，不因页面刷新、查询成功或恢复成功补充。资源不足时保留 unknown，不伪报恢复成功。
- 正常页面显示的是最近一次证据及其时间，不代表持续在线监测。未增加永久远端健康轮询；用户显式核实与启动/停止仍会产生必要连接。
- 服务独立记录启动规则身份。活动/未知服务所属规则的动作结构变更及删除受保护；名称、显示、手动/自动等不改变动作结构的编辑仍可进行。旧配置失去模板且不能恢复绑定时，保守检查独立服务登记，不以查找失败或动作已返回推断安全。
