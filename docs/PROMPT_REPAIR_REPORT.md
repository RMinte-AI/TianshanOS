# 用户提示与操作结果修复记录

本次包含历史 N01—N14 提示语核查及两轮审查确认的 R1—R6。代码已修复，本地主机和浏览器回归通过；未执行真实设备验收。

## 最终行为

- 实际内联翻译入口等待语言就绪，处理加载失败、超时、重试和快速切换；补齐中英文键与参数，内部枚举转换为用户可读状态。用户输入、文件名、路径、命令和远端输出不强制翻译。
- REST 业务失败保持既有返回契约，具体写操作显式校验结果。HTTP 错误保留 error/message，超时覆盖响应体读取；未确认的写入不当作成功，也不自动重发。
- 退出接口单独遵守 success:true 契约；其他接口不因此放宽。区分本地退出与服务端响应，旧退出回执不清除新的登录。
- SSH 完成事件、匹配成功/失败、超时、取消、冲突与未知状态分别处理；会话已受理不等于后台进程就绪。保持原匹配规则。
- 终端恢复等待实际确认；资源加载失败可重试，销毁实例不能迟到重连。LPMU 可达、不可达与检测未知分开，不自动重放电源脉冲。
- 上传、下载、删除及配置应用保留逐项/部分失败结果。下载只称已发起；上传不等于验证通过，验证通过不等于已应用。
- Toast 取消旧计时器，动态文本安全输出；有效新尝试可替换旧失败，迟到成功或失败不能覆盖新尝试。

## 两轮审查补修

|问题|修改|回归|
|---|---|---|
|R1 接口真实契约不一致|HTTP 错误先处理；退出、登录按自身契约；退出与新登录归属|401 error、成功退出、异常退出、其他接口拒绝宽松成功、迟到退出|
|R2 重复初始化与旧页面更新|首次启动/每次导航分离；主要页面读取校验导航有效性；只取消自己的订阅|已登录冷启动、旧页面迟到、失败重试、外部订阅保留、旧 finally 不释放新锁|
|R3 旧验证应用入口|绑定文件/路径/上传代次；重新上传立即失效；重叠写入不声称已确认最终文件|验证交替、旧成功晚到、已打开确认失效、同路径重叠上传|
|R4 新成功被旧错误遮住|有效尝试决定当前提示；不按响应到达顺序更新|快速重试、旧成功/旧失败分别晚到|
|R5 旧操作关闭新弹窗|成功、错误、finally 校验实例；任务记录独立于弹窗|A/B 弹窗交错、新按钮状态、关闭后结果保留|
|R6 上传后列表不刷新|固定目的目录；上传结果与刷新结果分开；目录请求代次校验|跨目录上传、同/跨目录刷新乱序、刷新失败不改上传成功统计|
