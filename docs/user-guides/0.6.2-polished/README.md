### 安全与语义核对

以下限制均已保留并核对中英文：

1. 断电、关闭风扇、低手动调速、网络切换、重启和 OTA 的影响与操作前检查。
2. 实测 RPM、已确认调速值、准备设置值不同；温度测试会替代正常温度来源，结束后须清除并确认恢复。
3. 曲线节点、百分比、温度、回差及时间范围没有删减；动作重复上限和命令参数也未删减。
4. 测试会执行动作；完成的操作不会因为清屏、停止或删除而撤销。
5. 远程后台任务不会因关闭 WebUI 或重启 TianshanOS 自动结束；停止请求之后仍须确认。
6. 服务状态未知或操作未结束时先核验或等待。删除不会替用户停止服务。
7. 停止服务、停用规则或停止引擎不会从规则中移除所使用的模板或指令。只读规则要由提供方签发调整包。
8. 通用文件上传及验证不等于应用设置；规则包须从自动化专用入口处理。专用验证能力不能套用于其他包。
9. 规则包要求可写 SD、设备凭证、CA 链、确认的时间及部署指定的可信签发方；root 登录或 HTTPS 证书不代替签发信任。
10. 导入不自动安装所需模板、指令和主机。运行变量缺少采样不一定是配置缺失；禁用配置须先核对是否允许启用。
11. 保存与运行版本分开；旧版本在重启前仍可能运行。重载或停止再启动引擎不代替设备重启。
12. 新规则尚未加载时不能手动执行；只读规则不能直接编辑、启停或删除。待删除规则不接受新触发，已发出的动作仍需检查。
13. 结果未确认时先读取列表及日志，不重复导入；文件、凭证或配置在预览后变化，要重新验证。
14. SD 卡与旧存储清理提示、目标证书变化后的新包安排、Webhook 暂不可用，以及降级不恢复配置格式的限制均保留。
15. 手动执行要求启用、手动权限和无同规则执行中；绕过自动条件与冷却，不绕过动作条件、延迟或重复。

章节层级及表格行数已对照中英文；所有原有数值仍在文本中。这些检查仅辅助人工语义复核，不将关键词或数值计数当成可读性评分。
